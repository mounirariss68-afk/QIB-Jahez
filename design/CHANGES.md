## How to add a line

Written by Claude at the end of each change, before the owner commits. "What changed" opens with one sentence a person would say, under twenty words, that names the change; the detail follows a colon, in short clauses separated by semicolons. CogniLab shows the opening sentence and keeps the detail behind "What it covers". File names and checks go in their own columns, never in it. A line without a "Verified" entry is not a finished change; a line without "Live" is a change the client cannot see yet. Lines here are the source for the handover pack's decisions file and for the implementation proposal's scope.
